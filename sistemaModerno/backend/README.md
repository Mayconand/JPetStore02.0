# Backend

Área reservada para a nova aplicação backend em Spring Boot.

Responsabilidades previstas:

- regras de negócio;
- API e controllers;
- autenticação e autorização;
- acesso aos dados;
- validações e tratamento de erros;
- testes unitários e de integração.

A versão do Java, do Spring Boot e a estratégia de persistência serão fixadas
antes da geração do projeto.
