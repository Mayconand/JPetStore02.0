# Frontend

Área reservada para a nova interface do JPetStore, baseada no Figma aprovado.

Responsabilidades previstas:

- catálogo e pesquisa;
- detalhes dos animais;
- carrinho e checkout;
- conta e histórico de pedidos;
- telas administrativas;
- componentes visuais reutilizáveis e responsivos.

O framework e as ferramentas de build serão definidos pela equipe antes da
geração do projeto.
