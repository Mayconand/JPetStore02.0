# Banco de dados

Área reservada para a evolução do banco de dados do sistema moderno.

Conteúdo previsto:

- migrations versionadas;
- dados iniciais para desenvolvimento;
- documentação do modelo;
- scripts de compatibilidade e migração do legado;
- ambiente PostgreSQL para desenvolvimento e testes.

Os dados e scripts originais permanecem em `sistemaLegado/db`.
