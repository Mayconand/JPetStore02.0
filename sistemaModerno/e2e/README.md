# Testes ponta a ponta

Área reservada para testes executados pela interface pública da aplicação.

Os mesmos cenários deverão ser executados contra o sistema legado e o sistema
moderno sempre que possível:

- navegação pelo catálogo e pesquisa;
- login, cadastro e edição de perfil;
- carrinho e alteração de quantidades;
- checkout e criação de pedidos;
- histórico e visualização de pedidos;
- controle de acesso às rotas protegidas.
